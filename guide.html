Windows 系统配置教程

本教程将指导你在 Windows 系统上安装和配置 Claude Code 与 Codex CLI，并使用第三方 API 中转服务。

重要提示： Claude Code 在 Windows 上的原生支持有限。推荐使用 WSL (Windows Subsystem for Linux) 或 Git Bash 以获得最佳体验。如果你选择原生安装，部分功能可能受限。

一、环境准备

1. 系统要求

  • Windows 10 或更高版本
  • 至少 4GB 内存
  • Node.js 18 或更高版本（npm 安装方式需要）

2. 安装 Node.js（npm 安装方式需要）

从 Node.js 官网下载并安装 LTS 版本：

# 下载地址 https://nodejs.org/ # 安装完成后，打开 PowerShell 验证 node --version # 应显示 v18.x.x 或更高 npm --version # 应显示 npm 版本号

二、安装 Claude Code CLI

方法一：原生二进制安装（推荐）

这是最简单稳定的安装方式，无需 Node.js 环境：

PowerShell 安装：

# 在 PowerShell 中运行（以管理员身份） irm https://claude.ai/install.ps1 | iex

命令提示符 (CMD) 安装：

# 在 CMD 中运行 curl -fsSL https://claude.ai/install.cmd -o install.cmd && install.cmd && del install.cmd

安装特定版本：

# 安装最新版本 irm https://claude.ai/install.ps1 | iex -args latest # 安装指定版本（如 1.0.58） irm https://claude.ai/install.ps1 | iex -args 1.0.58

方法二：npm 全局安装

# 使用 npm 全局安装（不要使用 sudo） npm install -g @anthropic-ai/claude-code # 如遇权限问题，可配置 npm 用户目录 npm config set prefix %USERPROFILE%\.npm-global # 然后将 %USERPROFILE%\.npm-global 添加到系统 PATH

方法三：通过 WSL 安装（推荐完整体验）

如果你想获得完整的 Claude Code 体验，建议使用 WSL：

# 1. 安装 WSL（在 PowerShell 管理员模式下运行） wsl --install # 2. 重启电脑后，打开 Ubuntu 终端 # 3. 在 WSL 中安装 Claude Code curl -fsSL https://claude.ai/install.sh | bash

三、安装 Codex CLI

# 使用 npm 全局安装 npm install -g @openai/codex # 升级到最新版本 npm i -g @openai/codex@latest
提示： Codex CLI 在 Windows 上的支持是实验性的，建议在 WSL 中使用以获得最佳体验。

四、配置 Claude Code 使用第三方 API

方法一：临时设置环境变量（当前会话有效）

打开 PowerShell 或命令提示符：

# PowerShell $env:ANTHROPIC_BASE_URL = "https://your-api-proxy.com" $env:ANTHROPIC_API_KEY = "sk-your-api-key-here" claude # 或 CMD set ANTHROPIC_BASE_URL=https://your-api-proxy.com set ANTHROPIC_API_KEY=sk-your-api-key-here claude

方法二：永久配置环境变量（推荐）

  1. 按 Win + R，输入 sysdm.cpl 并回车
  2. 点击「高级」选项卡 → 「环境变量」按钮
  3. 在「用户变量」区域点击「新建」
  4. 依次添加以下变量：
    变量名: ANTHROPIC_BASE_URL 变量值: https://your-api-proxy.com 变量名: ANTHROPIC_API_KEY 变量值: sk-your-api-key-here
  5. 点击「确定」保存所有对话框
  6. 重新打开命令行窗口使配置生效

方法三：使用 PowerShell 配置文件（推荐高级用户）

# 创建或编辑 PowerShell 配置文件 notepad $PROFILE # 在打开的文件中添加以下内容： $env:ANTHROPIC_BASE_URL = "https://your-api-proxy.com" $env:ANTHROPIC_API_KEY = "sk-your-api-key-here" $env:OPENAI_BASE_URL = "https://your-api-proxy.com/v1" $env:OPENAI_API_KEY = "sk-your-api-key-here" # 保存文件后，重新打开 PowerShell 即可生效

五、配置 Codex CLI 使用第三方 API

# PowerShell 临时设置 $env:OPENAI_BASE_URL = "https://your-api-proxy.com/v1" $env:OPENAI_API_KEY = "sk-your-api-key-here" codex # CMD 临时设置 set OPENAI_BASE_URL=https://your-api-proxy.com/v1 set OPENAI_API_KEY=sk-your-api-key-here codex

六、验证安装与配置

# 检查 Claude Code 安装 claude --version # 运行诊断检查（推荐） claude doctor # 测试 Claude Code claude "你好，这是一个测试" # 检查 Codex 安装 codex --version # 测试 Codex codex "用 Python 写一个 Hello World"

七、常见问题排查

# 检查环境变量是否生效 echo %ANTHROPIC_BASE_URL% # CMD echo $env:ANTHROPIC_BASE_URL # PowerShell # 如果命令找不到，检查 PATH where claude where codex # 网络连接测试 curl -I https://your-api-proxy.com
安全提醒：
  • 不要将 API 密钥提交到公开的代码仓库
  • 在共享设备上使用完毕后清除环境变量
  • 定期轮换你的 API 密钥

macOS 系统配置教程

本教程将指导你在 macOS 系统上安装和配置 Claude Code 与 Codex CLI，并使用第三方 API 中转服务。

一、环境准备

1. 系统要求

  • macOS 10.15 (Catalina) 或更高版本
  • 至少 4GB 内存
  • Node.js 18 或更高版本（npm 安装方式需要）

2. 安装 Homebrew（推荐）

Homebrew 是 macOS 上最流行的包管理器，强烈建议安装：

# 安装 Homebrew /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)" # 验证安装 brew --version

3. 安装 Node.js（npm 安装方式需要）

# 使用 Homebrew 安装（推荐） brew install node # 或使用 nvm 安装（更灵活的版本管理） curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.0/install.sh | bash source ~/.zshrc nvm install 20 nvm use 20 # 验证安装 node --version # 应显示 v18.x.x 或更高 npm --version

二、安装 Claude Code CLI

方法一：Homebrew 安装（推荐）

这是 macOS 上最简单的安装方式：

# 使用 Homebrew 安装 brew install --cask claude-code # 验证安装 claude --version

方法二：原生二进制安装

一行命令完成安装，无需 Node.js：

# 安装最新版本 curl -fsSL https://claude.ai/install.sh | bash # 安装特定版本 curl -fsSL https://claude.ai/install.sh | bash -s 1.0.58 # 安装最新版本（显式指定） curl -fsSL https://claude.ai/install.sh | bash -s latest

方法三：npm 全局安装

# 使用 npm 全局安装（不要使用 sudo） npm install -g @anthropic-ai/claude-code # 如遇权限问题，配置 npm 用户目录 mkdir ~/.npm-global npm config set prefix '~/.npm-global' echo 'export PATH=~/.npm-global/bin:$PATH' >> ~/.zshrc source ~/.zshrc
提示： 推荐使用 Homebrew 或原生二进制安装，这两种方式更稳定且能避免 Node.js 版本兼容问题。

三、安装 Codex CLI

方法一：Homebrew 安装

# 使用 Homebrew 安装 brew install --cask codex

方法二：npm 安装

# 使用 npm 全局安装 npm install -g @openai/codex # 升级到最新版本 npm i -g @openai/codex@latest

四、配置 Claude Code 使用第三方 API

方法一：临时配置（当前终端会话有效）

# 设置 API 基础地址 export ANTHROPIC_BASE_URL="https://your-api-proxy.com" # 设置 API 密钥 export ANTHROPIC_API_KEY="sk-your-api-key-here" # 启动 Claude Code claude

方法二：永久配置（推荐）

macOS Catalina 及以上版本默认使用 zsh，编辑配置文件：

# 使用 nano 编辑（适合新手） nano ~/.zshrc # 或使用 vim vim ~/.zshrc # 或使用 VS Code code ~/.zshrc

在文件末尾添加以下内容：

# ===== Claude Code & Codex API 配置 ===== # Claude Code export ANTHROPIC_BASE_URL="https://your-api-proxy.com" export ANTHROPIC_API_KEY="sk-your-api-key-here" # Codex export OPENAI_BASE_URL="https://your-api-proxy.com/v1" export OPENAI_API_KEY="sk-your-api-key-here"

保存后使配置生效：

# 重新加载配置 source ~/.zshrc # 验证环境变量已设置 echo $ANTHROPIC_BASE_URL echo $ANTHROPIC_API_KEY
提示： 如果你使用的是 bash 而非 zsh，请将 ~/.zshrc 替换为 ~/.bash_profile 或 ~/.bashrc。

五、配置 Codex CLI 使用第三方 API

# 临时设置（当前会话） export OPENAI_BASE_URL="https://your-api-proxy.com/v1" export OPENAI_API_KEY="sk-your-api-key-here" codex # 永久设置已包含在上面的 ~/.zshrc 配置中

六、验证安装与配置

# 检查 Claude Code 安装 claude --version # 运行诊断检查（推荐） claude doctor # 测试 Claude Code claude "你好，这是一个测试" # 检查 Codex 安装 codex --version # 测试 Codex codex "用 Python 写一个 Hello World"

七、常见问题排查

# 检查环境变量 env | grep -E "(ANTHROPIC|OPENAI)" # 检查命令是否在 PATH 中 which claude which codex # 网络连接测试 curl -I https://your-api-proxy.com # 如果 Homebrew 安装后命令找不到，运行 eval "$(/opt/homebrew/bin/brew shellenv)"
安全提醒：
  • 不要将 API 密钥提交到公开的代码仓库
  • 可以使用 macOS 钥匙串存储敏感密钥
  • 定期轮换你的 API 密钥

Linux 系统配置教程

本教程将指导你在 Linux 系统上安装和配置 Claude Code 与 Codex CLI，并使用第三方 API 中转服务。支持 Ubuntu、Debian、CentOS、Fedora、Arch Linux 等主流发行版。

一、环境准备

1. 系统要求

  • Ubuntu 20.04+ / Debian 10+ / CentOS 8+ / Fedora 33+ / Arch Linux
  • 至少 4GB 内存
  • Node.js 18 或更高版本（npm 安装方式需要）

2. 安装 Node.js

根据你的发行版选择对应的安装方式：

Ubuntu / Debian：

# 使用 NodeSource 仓库安装 Node.js 20.x curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash - sudo apt-get install -y nodejs # 验证安装 node --version # 应显示 v20.x.x npm --version

CentOS / RHEL / Fedora：

# CentOS / RHEL curl -fsSL https://rpm.nodesource.com/setup_20.x | sudo bash - sudo yum install -y nodejs # Fedora sudo dnf install nodejs npm # 验证安装 node --version npm --version

Arch Linux：

# 使用 pacman 安装 sudo pacman -S nodejs npm # 验证安装 node --version npm --version

使用 nvm 安装（推荐，适用于所有发行版）：

# 安装 nvm curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.0/install.sh | bash # 重新加载 shell 配置 source ~/.bashrc # 或 source ~/.zshrc # 安装并使用 Node.js 20 nvm install 20 nvm use 20 nvm alias default 20 # 验证 node --version npm --version
提示： 推荐使用 nvm 安装 Node.js，可以避免权限问题，并且方便管理多个 Node.js 版本。

二、安装 Claude Code CLI

方法一：原生二进制安装（推荐）

一行命令完成安装，无需 Node.js 环境：

# 安装最新版本 curl -fsSL https://claude.ai/install.sh | bash # 安装特定版本 curl -fsSL https://claude.ai/install.sh | bash -s 1.0.58 # 安装最新版本（显式指定） curl -fsSL https://claude.ai/install.sh | bash -s latest # 验证安装 claude --version

方法二：npm 全局安装

# 如果使用 nvm 安装的 Node.js（推荐，无需 sudo） npm install -g @anthropic-ai/claude-code # 如果使用系统包管理器安装的 Node.js sudo npm install -g @anthropic-ai/claude-code # 验证安装 claude --version
权限问题解决： 如果遇到权限错误，推荐使用 nvm 管理 Node.js，或者配置 npm 全局目录：
# 配置 npm 使用用户目录 mkdir -p ~/.npm-global npm config set prefix '~/.npm-global' # 添加到 PATH（添加到 ~/.bashrc 或 ~/.zshrc） echo 'export PATH=~/.npm-global/bin:$PATH' >> ~/.bashrc source ~/.bashrc # 然后无需 sudo 安装 npm install -g @anthropic-ai/claude-code

三、安装 Codex CLI

# 使用 npm 全局安装 npm install -g @openai/codex # 或使用 sudo（系统 Node.js） sudo npm install -g @openai/codex # 升级到最新版本 npm i -g @openai/codex@latest # 验证安装 codex --version

四、配置 Claude Code 使用第三方 API

方法一：临时配置（当前终端会话有效）

# 设置环境变量 export ANTHROPIC_BASE_URL="https://your-api-proxy.com" export ANTHROPIC_API_KEY="sk-your-api-key-here" # 启动 Claude Code claude

方法二：永久配置（推荐）

编辑你的 shell 配置文件：

# Bash 用户 nano ~/.bashrc # 或 vim ~/.bashrc # Zsh 用户 nano ~/.zshrc

在文件末尾添加以下内容：

# ===== Claude Code & Codex API 配置 ===== # Claude Code export ANTHROPIC_BASE_URL="https://your-api-proxy.com" export ANTHROPIC_API_KEY="sk-your-api-key-here" # Codex export OPENAI_BASE_URL="https://your-api-proxy.com/v1" export OPENAI_API_KEY="sk-your-api-key-here"

使配置生效：

# 重新加载配置 source ~/.bashrc # Bash 用户 # 或 source ~/.zshrc # Zsh 用户 # 验证环境变量 echo $ANTHROPIC_BASE_URL echo $ANTHROPIC_API_KEY

方法三：使用 systemd 用户环境变量（适用于桌面环境）

这种方式可以让环境变量在图形界面应用中也生效：

# 创建环境变量配置目录 mkdir -p ~/.config/environment.d # 创建配置文件 nano ~/.config/environment.d/api.conf

添加以下内容：

ANTHROPIC_BASE_URL=https://your-api-proxy.com ANTHROPIC_API_KEY=sk-your-api-key-here OPENAI_BASE_URL=https://your-api-proxy.com/v1 OPENAI_API_KEY=sk-your-api-key-here

重新登录或重启后生效。

五、配置 Codex CLI 使用第三方 API

# 临时设置 export OPENAI_BASE_URL="https://your-api-proxy.com/v1" export OPENAI_API_KEY="sk-your-api-key-here" codex # 永久设置已包含在上面的 shell 配置中

六、验证安装与配置

# 检查 Claude Code 安装 claude --version # 运行诊断检查（推荐） claude doctor # 测试 Claude Code claude "你好，这是一个测试" # 检查 Codex 安装 codex --version # 测试 Codex codex "用 Python 写一个 Hello World"

七、常见问题排查

# 检查环境变量 env | grep -E "(ANTHROPIC|OPENAI)" # 检查命令路径 which claude which codex # 检查 PATH 环境变量 echo $PATH # 网络连接测试 curl -I https://your-api-proxy.com # DNS 解析测试 nslookup your-api-proxy.com # 如果使用代理 export https_proxy=http://127.0.0.1:7890 export http_proxy=http://127.0.0.1:7890 export all_proxy=socks5://127.0.0.1:7890

常见错误及解决方案：

# 错误: EACCES permission denied # 解决: 使用 nvm 或配置 npm 用户目录 # 错误: command not found: claude # 解决: 检查 PATH 或重新安装 source ~/.bashrc # 或重新安装 curl -fsSL https://claude.ai/install.sh | bash # 错误: SSL/TLS 连接问题 # 解决: 更新 CA 证书 sudo apt update && sudo apt install ca-certificates # Ubuntu/Debian sudo yum update ca-certificates # CentOS/RHEL
安全提醒：
  • 不要将 API 密钥提交到公开的代码仓库
  • 考虑使用密钥管理工具（如 pass、gnome-keyring）
  • 设置文件权限保护配置文件：chmod 600 ~/.bashrc
  • 定期轮换你的 API 密钥
